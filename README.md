# DDRu — каталог скакалок

Фундамент сайта Double Dutch Russia: каталог → подбор → подготовка заявки → личное общение. Оплаты, корзины, checkout, сохранения заявок, авторизации и backend нет.

## Запуск

Node.js 22.13+ (для тестов с TypeScript), npm.

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000. Для production: `npm run build`, затем `npm start`.

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

## Маршруты

- `/` — главная, десять основных секций.
- `/catalog` — каталог четырёх базовых моделей, фильтрация.
- `/catalog/pvc-rope`, `/catalog/beaded-rope`, `/catalog/speed-rope`, `/catalog/double-dutch-rope` — страницы моделей.
- `/cart` — корзина нескольких позиций для подготовки одного общего запроса без оплаты.
- `/for-sections`, `/selection`, `/double-dutch`, `/education`, `/about`, `/contacts`.
- Неизвестные маршруты и товары — 404.

## Архитектура

- `src/types/product.ts` — Product, ProductVariant и ProductImage.
- `src/data/products.ts` — единый локальный источник моделей, цен и характеристик.
- `src/data/beaded-variants.ts` — 15 цветов бисерной DDRu с фотографиями пользователя; используется основным источником каталога.
- `src/data/loop-series.ts` — серии ручек LOOP внутри `Product.seriesOptions` для PVC и Beaded. Синие и розовые ручки, отдельные фото, статус `on-request`; цены и оптовый порог наследуются от товара. Выбор серии и цвета передаётся в LeadForm и текст заявки.
- `src/lib/catalog.ts` — слой чтения каталога, форматирование цены и оптовых условий. При интеграции Supabase заменить источник здесь и передавать данные через server-компоненты.
- `src/config/site.ts` — все контакты, основная навигация, название и адрес сайта.
- `src/lib/metadata.ts` — metadata, Open Graph, canonical. Реальный домен берётся из окружения; без него индексирование отключено.
- `src/types/inquiry.ts` — данные формы, товара/серии/цвета/количества и подбора, sourcePage, inquiryType, UTM, timestamp.
- `src/lib/selection.ts` — детерминированный подбор по задачам без дублей и проверка шагов. Возраст, размер группы, уровень и имеющийся инвентарь передаются тренеру; количество спортсменов не превращается в количество заказа.
- `src/lib/inquiry.ts` — `buildInquiryData()` формирует снимок данных, `buildInquirySummary()` — текст для личного сообщения.
- `src/lib/inquiry-handoff.ts` — подготовка продолжения общения; серверный адаптер не подключён.
- `src/components/inquiry` — единые LeadForm и InquiryModal с режимами product / selection / section / cart / general (нативный dialog, Escape, возврат фокуса). Обязательны только имя и контакт.
- `src/components/cart` — локальная корзина: товар, серия, цвет и количество сохраняются в браузере и передаются в InquiryModal в режиме cart.
- `src/components/catalog` — ProductCard, ProductMedia, CatalogGrid, ProductDetail.
- `src/components/layout`, `src/components/ui` — общая навигация, подвал и секции.
- `src/data/education.ts` — направления обучения; будущие курсы можно подключить отдельным источником без LMS на этом этапе.

Данные формы живут только в памяти страницы. Перезагрузка или закрытие диалога сбрасывает их; «Запрос подготовлен» не означает отправку. Копирование имеет запасной путь — доступное текстовое поле. Предпочтительный мессенджер выводится первым. Контекст товара/серии/цвета/количества подставляется при открытии; смена товара сбрасывает цвет.

Розница — 1–29 единиц, опт — от 30. Для Double Dutch единица — **комплект из двух скакалок**. Оптовые цены хранятся в данных; в интерфейсе карточки основная цена розничная. Условия смешанной партии согласуются лично.

Корзина не рассчитывает итоговую стоимость и не оформляет покупку. Она объединяет выбранные позиции в один текст запроса для дальнейшего личного согласования.
