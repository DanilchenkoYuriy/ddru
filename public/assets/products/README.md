# Фотографии товаров

Подключены 15 оригинальных фотографий бисерных DDRu, переданных пользователем. Источник соответствия вариантов: `src/data/beaded-variants.ts`.

- Основное фото в каталоге и на главной — чёрная бисерная DDRu; оно совпадает с первоначально выбранным цветом в карточке.
- Каждый цвет переключает фотографию и передаётся в заявку. Фотографии сохранены без обработки; `next/image` оптимизирует выдачу браузеру.
- `rad.jpg` соответствует красному цвету; `terakot.jpg` фактически содержит бирюзовую скакалку, поэтому вариант подписан «Бирюзовый». Имена исходных файлов сохранены.
- Оттенки переключателей приблизительные, наличие по фотографии не подтверждается.
- Исходные копии двух бисерных фотографий LOOP также сохранены в `assets/pending/loop`.
- Основные фото ПВХ, скоростной и комплекта Double Dutch подключены без обработки. В публичном каталоге у четырёх товаров больше нет заглушек.
- Четыре фото LOOP в `public/assets/products/loop` подключены к выбору ручек ПВХ и бисерного товара. Серия описана в `src/data/loop-series.ts` со статусом `on-request` и наследует цены DDRu. Отдельных карточек LOOP нет.

У изображений есть `src` и русский `alt`. Товарные фото загружаются только из локальной папки public.
